# Сайт Ники Дупиной

Лендинг, личный кабинет клиента и админка. Фронт — статичные страницы без сборщика, бэкенд — папка `server/`.

## Запуск на своём компьютере

Нужен только [Docker Desktop](https://www.docker.com/products/docker-desktop/) (запущенный).

```
./start.sh
```

Первый запуск занимает пару минут. Скрипт сам создаст файл `.env` с локальными настройками, поднимет базу, хранилище видео и почту, загрузит демо-данные.

| Что | Адрес |
|---|---|
| Сайт, ЛК, админка | http://localhost:3000 |
| Письма с кодами входа | http://localhost:8025 |

Остановить: `docker compose down`. Стереть все локальные данные и начать заново: `docker compose down -v`.

## Как устроено

```
браузер ──► nginx (на бою) ──► статика сайта (html, css, js)
                         └──► /api/*  ──► server (Node.js + Fastify) ──► PostgreSQL
браузер ──► подписанная ссылка ──► S3 (видео, напрямую, минуя сервер)
```

Локально nginx нет: статику и `/api` раздаёт сам сервер на порту 3000.

```
server/
  src/          код сервера (config.js читает все настройки из переменных окружения)
  migrations/   изменения базы по порядку (001_init.sql — все таблицы)
  scripts/      setup.js: миграции → хранилище → демо-данные (не на бою)
  seed/         демо-данные и 5 коротких демо-видео
  s3/cors.xml   CORS для боевого бакета
  test/         автотесты
.env.example    список всех настроек без значений
```

## Переход на боевой сервер

Код не меняется, меняются только значения в `.env` на сервере (имена из `.env.example`): адрес сайта, база, S3 Timeweb, почтовый сервис, ключи Robokassa, секрет сессий. `NODE_ENV=production` включает строгие проверки: адрес только https, секрет не короче 64 символов, демо-данные не загружаются.

### CORS боевого бакета
Файл `server/s3/cors.xml`: заменить `https://example.ru` на домен сайта и вставить в настройки CORS бакета в панели Timeweb Cloud (раздел S3-хранилища → бакет → настройки). Где именно лежит этот пункт в панели — не проверено, уточним при подключении. `ExposeHeaders ETag` обязателен: без него загрузка видео частями из браузера не работает.
